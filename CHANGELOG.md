# Changelog

## 1.0.0 — Version 1 baseline

First public-release preparation of the frozen Version 1 baseline:

- `odop-json` representation version `1.0` parsing with receipt preservation;
- Draft 2020-12 JSON Schema structural handling;
- deterministic local structural validation results;
- Version 1 fixtures and focused unit/integration tests.

This release does not claim protocol conformance, replay, verification, trust,
registry operation, interoperability, transport, persistence, or production
security certification.
