# Governance

## Authority

The frozen [ODOP Protocol Specification](protocol/ODOP-Protocol-Specification.md)
is the sole authority for protocol semantics. The frozen
[Reference Implementation Architecture](architecture/REFERENCE_IMPLEMENTATION_ARCHITECTURE.md)
governs the non-normative implementation boundary. Supporting publications do
not override either document.

## Review boundaries

Changes to code, examples, fixtures, schemas, and supporting publications must
state their authority and scope. No contributor may establish protocol meaning
through code, configuration, tests, provider behavior, or documentation.

When an issue may require protocol-semantic interpretation, contributors must
contain the implementation change and use the Protocol-Semantic Escalation
process described by Architecture Chapter 27 and Protocol Chapter 34. The
issue record is not a local semantic resolution.

Version 1 remains bounded to local structural handling. Future-scope work
requires an approved, separately scoped milestone.
