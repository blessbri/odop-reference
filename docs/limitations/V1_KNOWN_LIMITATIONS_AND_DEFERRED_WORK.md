# Version 1 Known Limitations and Deferred Work

Non-blocking limitations: resource-limit values are unset by default; only
configured received-byte and reported-issue bounds are enforced; duplicate
detection is parser-only; metadata and extension-key contents remain opaque.

Deferred work: replay, lifecycle/holder derivation, policy evaluation,
verification/trust/profiles, registries, interoperability, conformance,
transport, persistence, recovery, replication, consensus, blockchain, and
post-quantum work. No PSE is open.
