# Version 1 Capability Declaration

**Status:** Bounded local capability declaration; not a conformance claim.

Supports only representation id odop-json version 1.0 with Protocol version
1.0, UTF-8 receipt preservation, duplicate detection, Draft 2020-12 Schema
structural handling, local validation issues, and fixture-backed local tests.

Does not support replay, lifecycle/holder derivation, policy evaluation,
verification/trust/profiles, registries, interoperability, conformance,
canonicalization, signing, transport, persistence, recovery, replication,
consensus, blockchain, or post-quantum behavior. This declaration is scoped to
the approved supporting publications and does not assert Protocol validity.
