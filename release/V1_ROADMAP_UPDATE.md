# ODOP Roadmap Update — Version 1 GA Preparation

**Status:** Version 1 feature-complete; GA documentation package prepared.

## Version 1

Version 1 delivers bounded local ODOP JSON representation handling:
received-byte preservation, strict parsing, Draft 2020-12 Schema evaluation,
local structural validation, fixture-backed integration tests, and release audit.
The approved capability declaration and limitations remain authoritative for its
scope.

## GA gate

Proposed release tag: v1.0.0-rc.1. GA approval requires review of the release
documentation package; it does not expand capability or publish supporting
drafts as standards.

## Future planning gate

Version 2 planning may begin only after formal owner approval. No replay,
verification, registry, interoperability, conformance, transport, persistence,
recovery, replication, consensus, blockchain, or post-quantum work is
authorized by this roadmap update.
