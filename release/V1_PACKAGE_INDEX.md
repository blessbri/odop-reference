# Version 1 Package Index

- `odop_model.artifact_boundary`: receipt and registered parser boundary.
- `odop_model.odop_json_v1`: strict JSON parsing and Schema evaluation.
- `odop_model.validation`: local structural result model and configured limits.
- `odop_processing`: replay interfaces only; excluded from Version 1 capability.
- `odop_verification`: contracts only; excluded from Version 1 capability.
- `odop_persistence`, `odop_external`, `odop_deployment`: limited contracts/test
  adapters; excluded from Version 1 capability.
