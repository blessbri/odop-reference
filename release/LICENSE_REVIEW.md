# License Review

## Proposed license

This independent public repository prepares the Apache License, Version 2.0 in
[`LICENSE`](../LICENSE). It replaces no license in the frozen internal
baseline; it is the proposed grant for this public distribution.

## Reviewed material

The copied Version 1 Protocol, Architecture, supporting materials, Python
source, tests, fixtures, and release records were locally reviewed for existing
license notices and third-party attribution requirements. No incompatible
third-party license notice was identified in the selected public subset.

## Required confirmation before publication

The frozen baseline's `LICENSE.md` stated that no project license had then been
selected. Before upload, the designated copyright owner must confirm authority
to release every copied baseline work under Apache-2.0 and confirm that every
contributor has granted the necessary rights. This distribution does not infer
that authority from the absence of a notice.

## Excluded material

The prior baseline `LICENSE.md` is excluded because it is a status notice, not
a license grant. It is superseded here by the proposed Apache-2.0 `LICENSE`.
No known third-party component is included beyond the declared Python runtime
dependency `jsonschema`, which is installed by users rather than vendored.
