# GitHub Release Checklist

The following owner decisions must be recorded before publication:

- [ ] Repository name: `odop-reference` confirmed.
- [ ] GitHub organization or account selected.
- [ ] Default branch and branch protection configured.
- [ ] Release tag confirmed (Version 1 record proposes `v1.0.0-rc.1`).
- [ ] Release title and notes approved.
- [ ] Apache-2.0 copyright authority confirmed.
- [ ] Security reporting contact/channel configured.
- [ ] Issue tracker enabled and labels configured.
- [ ] Discussions enabled or deliberately disabled.
- [ ] Package-publication decision recorded (none is required for Version 1).
- [ ] Website/documentation URL decision recorded.
- [ ] GitHub Actions run successfully in the target repository.
