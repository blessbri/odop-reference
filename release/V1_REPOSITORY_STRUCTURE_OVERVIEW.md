# Version 1 Repository Structure Overview

| Path | Version 1 role |
|---|---|
| protocol/ | Frozen Protocol source |
| schemas/odop-json-v1/ | Draft JSON Schema package |
| specs/representations/odop-json-v1/ | Draft representation supporting publication |
| packages/protocol-model/ | Artifact boundary, JSON parser, structural validator |
| test/protocol/ | Unit and integration tests |
| specs/fixtures/v1-json/ | Fixture catalogue manifest |
| docs/ | Governance, design, audit, GA documentation |

Other package and adapter areas remain limited or deferred as declared in the
Version 1 capability declaration.
